# My_1st-Repository.
Data Analytics Project works
SUM = To find the sum of the products we need to calculate the total value of the product 
COUNT= To find the count of the product we need to use count formula  
AVERAGE = To find the average of the product we need to use mean formula
MIN = To find the lowest price of the product 
MAX = To find the highest price of the product
IF function : To Categorize product based on price
SUMIF : To Calculate the price of a specific products
COUNTIF : To Count the product with specific price range
LEFT : To find the specific number or value form the begining.
RIGHT : To find the specific number or value form the END.
MID : To find the specific number or value form the Middle
